# obox-builder

Model-driven forms, views, and REST APIs for FastAPI applications using SQLAlchemy.

## Install

```shell
uv add obox-builder
```

## Documentation

- [Quickstart](docs/quickstart.md)
- [Core specification](docs/spec.md) for the public contract

## Requirements

- Python 3.11 or newer
- FastAPI
- SQLAlchemy 2

Optional dependency groups provide PostgreSQL drivers, SQLite async support, and authentication.
