# Quickstart

Create and run the small FastAPI project generated by `obox startproject`.

## Requirements

- Python 3.11 or later
- [uv](https://docs.astral.sh/uv/)
- Git

## 1. Get the source and generate a project

This guide uses a local checkout so the generated project can depend on the
source tree:

```shell
git clone https://github.com/vinhgiga/obox-builder
cd obox-builder
uv sync --all-extras
uv run obox startproject demo ../demo
cd ../demo
```

The scaffold contains only the application files:

```text
demo/
├── .editorconfig
├── justfile
├── main.py
└── setting.py
```

It intentionally does not create `pyproject.toml` or a pre-commit configuration;
you own those project-level choices.

## 2. Add project dependencies

Create a `pyproject.toml` for the application. The local source entry points to
the checkout beside `demo`:

```toml
[project]
name = "demo"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
    "obox-builder[sqlite]>=0.4,<0.5",
    "uvicorn>=0.35,<1",
]

[tool.uv.sources]
obox-builder = { path = "../obox-builder", editable = true }
```

Then install the project and its dependencies:

```shell
uv sync
```

When installing obox-builder from a package index, remove the `[tool.uv.sources]`
section.

## 3. Run the application

```shell
uv run uvicorn main:app --reload
```

Open <http://127.0.0.1:8000/>. The generated root route returns a welcome
message. This starter does not register a model or expose CRUD routes; see the
[core specification](spec.md#2-quickstart-and-registration) for resource
registration and customization.

The generated settings use SQLite and a development secret by default. They can
be overridden with `OBOX_DATABASE_URL`, `OBOX_DEBUG`, and `OBOX_SECRET_KEY`.
Set `OBOX_DEBUG=false` and a private `OBOX_SECRET_KEY` before deploying the
application.

The generated entrypoint keeps FastAPI as the application and installs Auth
before any resource registration:

```python
import setting
from fastapi import FastAPI
from obox_builder import Obox
from obox_builder.contrib.auth import Auth

app = FastAPI(title=setting.PROJECT_NAME, debug=setting.DEBUG)
obox = Obox(app, settings="setting", plugins=[Auth(secure=not setting.DEBUG)])
```

Use `obox.register(MyBuilder)` for customized resources or
`obox.register(MyModel)` for default staff-only resources. Additional plugins
install with `obox.install(plugin)` before startup, in dependency order.

To serve an existing SPA build, use FastAPI directly:

```python
app.frontend("/", directory="web/dist", fallback="index.html")
```

API routes retain priority. Set cache headers in the deployment configuration.
