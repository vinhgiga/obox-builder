# Common feature examples

Use these recipes for the everyday tasks involved in building an internal app.

- [Register a resource](register-resource.md): expose a selected model through
  generated forms, views, and API routes.
- [Protect data](auth-and-permissions.md): install Auth and add a row scope.
- [Attach files](file-attachments.md): declare an attachment field and storage.
- [Start a project](../quickstart.md): create the scaffold and first resource.

For specialized examples, use the [Views](../views/index.md),
[APIs](../apis/index.md), [Forms](../forms/index.md), [Pages](../pages/index.md),
and [Components](../components/index.md) sections.
