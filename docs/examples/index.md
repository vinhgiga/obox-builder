# Examples

Start with a generated app, then browse the examples by the kind of work you
want to do.

<div class="grid cards" markdown>

-   **Start a project**

    ---

    Install Obox Builder, create the scaffold, run migrations, and sign in.

    [Open the quickstart](quickstart.md)

-   **Features**

    ---

    Common recipes for registering resources, protecting data, and adding files.

    [Browse feature examples](features/index.md)

-   **Views**

    ---

    Configure list columns, search, filters, ordering, and pagination.

    [Browse view examples](views/index.md)

-   **APIs, Forms, Pages, and Components**

    ---

    Create a resource API, customize forms, compose pages, and add components.

    [Open the examples](apis/index.md)

</div>

The examples use the generated `main.py`, `models.py`, and `setting.py` files.
They assume the local server is running and a user with the required resource
permissions is signed in. See the navigation under Examples for the complete
Features, Views, APIs, Forms, Pages, and Components structure.
